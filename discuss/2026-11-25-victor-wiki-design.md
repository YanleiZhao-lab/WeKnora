# victor_wiki 部署与维护方案

采用 WeKnora v0.9.1 完整服务端形态：前端、Go 服务、PostgreSQL/pgvector、Redis、DocReader，以及本地 Ollama。资料、索引、模型、备份均保留在联想电脑。不开启云模型、云解析或云端追踪。

GitHub fork 为 YanleiZhao-lab/WeKnora。main 跟随官方；personal/victor-wiki 保存个人定制。名称为 victor_wiki，名称与 Logo 通过独立品牌配置管理；未提供 Logo 时显示名称文字，保留上游版权。

程序与脚本位于 /home/lenovo/victor_wiki；持久数据、模型及备份位于 /data1/victor_wiki。数据盘 noexec 不作程序安装位置，不修改既有挂载方式。镜像获取使用机器已有本地代理，应用和模型不配置公网代理。

定期获取官方稳定版，在独立 worktree 合并与构建；冲突或构建失败保留正在运行的版本。升级前备份数据库和配置，并记录旧镜像、版本与恢复命令。提供显式升级入口；定时任务在候选构建、验证和备份通过后自动升级。状态存储镜像变化时停止并要求迁移评估；数据库迁移失败不得仅回退镜像。

验收：服务健康、个人品牌、注册登录、真实测试文档入库与检索、引用与本地问答、重启持久性、脚本语法与配置校验。浏览器检查实际页面。未完成的能力分别报告，不将页面可打开视为完整验收通过。
